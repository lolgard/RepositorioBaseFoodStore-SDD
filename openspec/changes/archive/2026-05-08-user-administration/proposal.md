# Change: user-administration

## What
Panel de administración de usuarios: listado con filtros, edición de datos y roles, y desactivación lógica.

## Why
- **US-053**: Como admin, quiero ver el listado de todos los usuarios.
- **US-054**: Como admin, quiero editar los datos y el rol de un usuario.
- **US-055**: Como admin, quiero desactivar un usuario para que no pueda acceder al sistema.

## Dependencies
- `auth-system`: Usuarios con roles ya existen.
