# Change: order-visualization

## What
Páginas frontend para visualizar pedidos: listado del cliente, detalle con snapshots e historial, y listado completo para Gestor/Admin con filtros.

## Why
- **US-049**: Como cliente, quiero ver mis pedidos anteriores para hacer seguimiento.
- **US-050**: Como cliente, quiero ver el detalle de un pedido específico.
- **US-051**: Como gestor, quiero ver todos los pedidos con filtros.
- **US-052**: Como gestor, quiero ver el detalle completo de cualquier pedido.

## Dependencies
- `order-creation`: Los pedidos existen con items e historial.
